## 📖 О проекте

**UndertaleConsole** — это учебный проект по созданию текстовой RPG на языке C#. Проект создан для практики объектно-ориентированного программирования, работы с файлами и построения игровых циклов.

Игра переносит атмосферу Подземелья прямо в окно консоли. Вам предстоит исследовать локации, сражаться с монстрами, зарабатывать золото, покупать еду и, конечно же, попытаться выбраться наружу, не потеряв решимость (и HP). Игра находится в стадии активной разработки.

## ✨ Ключевые особенности

*   ⚔️ **Пошаговая боевая система** — Атакуй, защищайся или используй предметы. 
*   🛡️ **Механика парирования** — При защите есть шанс, что враг промахнётся и ударит сам себя!
*   🎒 **Инвентарь и магазин** — Покупка и продажа предметов для восстановления сил.
*   📈 **Прокачка** — Получай опыт (XP), повышай уровень и увеличивай свою атаку.
*   👹 **Сражения с боссами** — Встреться с Флауи, Андайн, MTT и легендарным Золотым Сансом.
*   💾 **Система сохранений** — Прогресс сохраняется в файл `save.txt`, игра не начинается с нуля при каждом запуске.

## 🚀 Как запустить и играть

### Вариант 1: Готовый файл (Быстрый старт)
Если вы просто хотите поиграть и у вас установлена Windows, готовый скомпилированный файл находится по пути:
`Undertale\Undertale\bin\Release\Undertale.exe`
Просто запустите его двойным кликом.

*(Примечание: В зависимости от версии Visual Studio путь может немного отличаться, ищите папку `bin` внутри проекта).*

### Вариант 2: Запуск из исходного кода
Для запуска через код вам понадобится **Visual Studio** (или любая другая IDE с поддержкой C#).

1. Склонируйте репозиторий или скачайте его как ZIP-архив.
2. Откройте файл решения `.sln` в Visual Studio.
3. Нажмите кнопку **Запустить** (или клавишу `F5` на клавиатуре).

## 🕹️ Управление

Игра полностью текстовая. Управление осуществляется вводом цифр с клавиатуры для выбора нужного пункта меню и нажатием `Enter` для подтверждения действий.
