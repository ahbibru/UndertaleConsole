## 📖 О проекте

**UndertaleConsole** — это учебный проект по созданию текстовой RPG на языке C#. Проект создан для практики объектно-ориентированного программирования, работы с файлами и построения игровых циклов.

Игра переносит атмосферу Подземелья прямо в окно консоли. Вам предстоит исследовать локации, сражаться с монстрами, зарабатывать золото, покупать еду и, конечно же, попытаться выбраться наружу, не потеряв решимость (и HP). Игра находится в стадии активной разработки.

## 🚀 Скачать и играть

Готовый скомпилированный файл игры доступен в разделе **Releases**.

### 👉 [**Скачать Undertale.exe (v1.0.1)**](https://github.com/ahbibru/UndertaleConsole/releases/tag/1.0.1)

**Инструкция по запуску:**
1. Перейдите по ссылке выше.
2. В разделе **Assets** (Ресурсы) скачайте файл `Undertale.exe`.
3. Запустите файл на Windows.
4. Наслаждайтесь игрой!

> **Важно:** Игра предназначена для Windows и работает в консольном режиме. Убедитесь, что на вашем компьютере установлен .NET Framework (обычно он уже есть в Windows 10/11).

## ✨ Ключевые особенности (v1.0.1)

*   ⚔️ **Пошаговая боевая система** — Сражайтесь с монстрами: Фроггит, Темми, Цундереплан, Араон, Молдсмол.
*   👹 **Битвы с боссами** — Встретьтесь с Андайн, MTT и легендарным Золотым Сансом.
*   🎒 **Экономика и магазин** — Зарабатывайте золото, покупайте и продавайте лечебные предметы (Монстрская конфета, Морской чай, Овощная лапша, Гламбургер и др.).
*   📈 **Прокачка** — Получайте опыт (XP), повышайте уровень и увеличивайте атаку.
*   💾 **Сохранение и загрузка** — Полноценная система сохранений с защитой от ошибок (`try-catch`), чтобы предотвратить вылеты.
*   🎨 **Ретро ASCII-графика** — Уникальные ASCII-арты для персонажей и боссов.

## 🛠️ Технологии

*   **Язык:** C#
*   **Платформа:** .NET Framework 4.7.2
*   **Парадигма:** Объектно-ориентированное программирование (ООП)
*   **Работа с файлами:** `System.IO` (для системы сохранений)
